# چالش‌های فاز ۱۲ — JVM در حد یادگیرنده

جواب این فایل جای دیگری است.

## ۱

`Hello.class` در پوشهٔ `phase-01` است. از پوشهٔ خانه این را می‌زنی:

```bash
java Hello
```

متن خطا چیست، و مقصر نصب جاوا است یا مسیر؟

## ۲

برای `factorial(3)` چند frame روی هم زنده است، درست قبل از برگشتِ عمیق‌ترین فراخوانی؟ هر frame چه `n` دارد؟

## ۳

هزار `Book` را در `ArrayList` نگه داشته‌ای. garbage collector حق دارد وسط حلقه جمع‌شان کند؟ یک دلیل.

## ۴

خروجی `javap -c -p Hello` را چه می‌نامی، کد منبع یا bytecode؟ دنبال کدام نام می‌گردی تا مطمئن شوی `main` آنجاست؟

## ۵

این فرمان classpath را کجا می‌گذارد؟

```bash
java -cp . Hello
```

اگر `.` همان پوشه‌ای باشد که `Hello.class` آنجاست، با `java Hello` از همان پوشه فرق عملی دارد؟

## ۶

چرا در این مسیر فایل `module-info.java` نمی‌سازی، حتی با JDK 21؟

## ۷

یک جمله بنویس که فرق stack و heap را با همین متد بگوید: متغیر `n` کجاست و شیء `Book` که با `new` ساخته شده کجاست.
