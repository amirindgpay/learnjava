# پاسخ فاز ۴ — متد و آرایه

## ۱

`x` می‌ماند `1`. `scores[0]` می‌شود `2`. `replace` اثری ندارد. `int` کپی می‌شود. آرایه همان شیء است، ولی نسبت دادن پارامتر به یک آرایهٔ تازه فقط متغیر داخل متد را عوض می‌کند.

## ۲

نوع برگشت overload نمی‌سازد. هر دو متد یک نام و یک پارامتر `int` دارند، پس برای کامپایلر یکی هستند.

## ۳

`4.0`. جمع ۱۲ است و تقسیم بر `3` صحیح است. نوع برگشت `double` تقسیم داخل بدنه را اعشاری نمی‌کند.

## ۴

آرایهٔ خالی خانهٔ صفر ندارد. `scores[0]` پرتاب می‌کند `ArrayIndexOutOfBoundsException`. قبل از آن `length` را ببین.

## ۵

جابه‌جایی روی همان `scores` است و همان آرایه برمی‌گردد. برای سالم ماندن ورودی باید آرایهٔ تازه بسازی.

## ۶

`for` معمولی. `for-each` اندیس نمی‌دهد.

## ۷

این overloading است.

```java
static double average(int[] scores)
```
