# پاسخ فاز ۶ — وراثت، interface و چندریختی

## ۱

بدن `Circle`. نوع متغیر فقط اجازهٔ صدا زدن `area` را می‌دهد. شیء واقعی بدن را انتخاب می‌کند.

## ۲

`main` به نوع فرزند `if` زده. فرزند سوم این حلقه را دوباره باز می‌کند. باید `shape.area()` را مستقیم صدا بزنی.

## ۳

کامپایل نمی‌شود. از کلاس `abstract` نمی‌شود `new` کرد.

## ۴

`Area` متد دیگری است، نه پوشش `area`. بدون `@Override` کامپایلر این اختلاف اسم را نمی‌گیرد و صدا زدن `area` هنوز بدن والد است.

## ۵

interface. وضعیت و کد مشترک نداری. فقط قرارداد `pay` است.

## ۶

`true`. `record` از روی componentها `equals` می‌سازد.

## ۷

اگر یکی از ثابت‌های enum در `switch` expression نباشد و `default` هم نگذاری، کامپایلر همان جا را رد می‌کند.
