# پاسخ فاز ۳ — شرط و حلقه

## ۱

`ABC`. شکل کلاسیک بدون `break` از `case 1` به `case 2` و `default` نشت می‌کند.

## ۲

`A`. فلش به شاخهٔ بعدی نمی‌رود و expression فقط همان شاخه را برمی‌گرداند.

## ۳

`1`. `do-while` بدنه را قبل از شرط اجرا می‌کند، حتی اگر شرط از اول غلط باشد.

## ۴

`n` هیچ‌جا زیاد نمی‌شود، پس `n <= 3` همیشه راست است. جملهٔ پایان این بود که `n` از ۳ بزرگ‌تر شود، ولی کدی برای آن قدم نیست.

## ۵

`Fizz`. ۱۵ بر ۳ بخش‌پذیر است و شاخهٔ اول برمی‌گردد. شاخهٔ `FizzBuzz` مرده است چون هر مضرب ۱۵ قبلاً مضرب ۳ بوده.

## ۶

`1` و `2` و `4`. `continue` دور ۳ را چاپ نمی‌کند. `break` قبل از چاپ ۵ حلقه را می‌بندد.

## ۷

نه. `switch` expression روی `int` باید همهٔ مقدارها را بپوشاند و اینجا `default` ندارد.

## ۸

```java
for (int n = 12; n <= 16; n = n + 2) {
    System.out.println(n);
}
```

شرط `n <= 16` همان جملهٔ پایان است: تمام می‌شود وقتی عدد از ۱۶ بزرگ‌تر شود.
