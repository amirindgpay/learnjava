# پاسخ فاز ۱ — محیط و اولین برنامه

## ۱

کامپایل نمی‌شود. class عمومی `Hello` باید در فایلی به نام `Hello.java` باشد، نه `Main.java`.

## ۲

`ClassNotFoundException` برای نام `Hello.class`. فرمان `java` پسوند نمی‌گیرد. نام class همان `Hello` است.

## ۳

چاپ `1`. از `//` تا آخر خط کامنت است و `x = 2` اجرا نمی‌شود.

## ۴

برای یک فایل بدون package اجرا می‌شود و `.class` روی دیسک نمی‌ماند. از Java 11 به بعد `java` می‌تواند همان یک فایل را در حافظه کامپایل کند. مسیر عادی این دوره هنوز `javac` و بعد `java` است.

## ۵

سمیکالن خط `println("یک")` جا مانده. `javac` همان خط را نشان می‌دهد، نه خط بعدی را.

## ۶

اول `javac` را به همان JDK 21 می‌رسانی. دو فرمان از دو نصب متفاوت‌اند و بایت‌کدی که یکی می‌سازد با زمان اجرای دیگری یکی نیست.

## ۷

`javac Hello.java` و بعد `java Hello`. فایل تازه `Hello.class` است.
