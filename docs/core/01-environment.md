# فاز ۱ — محیط و اولین برنامه

این درسنامه برای Java 21 است و از صفر شروع می‌شود. قبل از هر محاسبه، باید بتوانی یک فایل را به برنامهٔ در حال اجرا تبدیل کنی و اگر جاوا خطا داد، شمارهٔ خط را در پیام پیدا کنی.

## چرا این‌طور کار می‌کند

JDK همان بسته‌ای است که نصب می‌کنی. داخلش دو فرمان هست که این مسیر با آن‌ها کار می‌کند: `javac` متن را به فایل `.class` تبدیل می‌کند، و `java` همان فایل را اجرا می‌کند. `java -version` و `javac -version` هر دو باید ۲۱ را نشان بدهند. اگر یکی ۲۱ باشد و دیگری نه، داری دو نصب را قاطی می‌کنی.

برنامه یک فایل متنی با پسوند `.java` است. اگر class را `public` اعلام کنی، نام فایل و نام class باید یکی باشد: class به نام `Hello` فقط در `Hello.java`. جاوا برنامه را از متد `main` شروع می‌کند. `static` را فاز ۵ باز می‌کنیم. تا آن‌جا این امضا را عین همین شکل بنویس.

`System.out.println` یک خط می‌نویسد و خط بعد را از سر می‌گیرد. هر جملهٔ جاوا با `;` تمام می‌شود. کامنت `//` تا آخر همان خط برای جاوا نامرئی است و برای توست.

پیام `javac` شمارهٔ خط را دارد. آن شماره همان جایی است که باید نگاه کنی، نه اینکه کل فایل را از نو بنویسی.

## قاعده

نسخه را قبل از هر تمرین قفل کن. نام فایل با نام class یکی باشد. برنامه را از همان پوشه، اول با `javac` و بعد با `java`، اجرا کن. اگر کامپایل شکست، اول شمارهٔ خط پیام را بخوان.

## مثال

```java
public class Hello {
    public static void main(String[] args) {
        // این برنامه یک خط چاپ می‌کند
        System.out.println("...");
    }
}
```

```bash
javac Hello.java
java Hello
```

`javac` کنار فایل متن، `Hello.class` می‌سازد. `java Hello` همان را اجرا می‌کند. پسوند `.class` را در فرمان دوم نمی‌نویسی.

## اشتباه رایج

جا ماندن یک `;`. برنامه اجرا نمی‌شود و پیام `javac` شمارهٔ خط را می‌گوید. سمیکالن را همان‌جا برگردان، نه اینکه خط‌های سالم را هم عوض کنی.

## تمام است وقتی

بدون جزوه یک class با `main` بسازی، `javac` و `java` را درست صدا بزنی، و اگر سمیکالن جا مانده باشد از روی پیام کامپایلر همان خط را نشان بدهی.
