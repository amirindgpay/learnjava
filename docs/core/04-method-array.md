# فاز ۴ — متد و آرایه

این درسنامه برای Java 21 است. `main` نباید همه‌چیز را خودش حساب کند. متد یک کار را با اسم، ورودی و خروجی جدا می‌کند. آرایه چند مقدار از یک نوع را پشت هم نگه می‌دارد.

## چرا این‌طور کار می‌کند

متد `static` را بدون ساختن شیء صدا می‌زنی. فاز ۵ فرق آن را با متد شیء باز می‌کند. تا آن موقع متدها را `static` و داخل همان class برنامه بنویس. پارامترها ورودی‌اند. `return` خروجی را برمی‌گرداند و از متد بیرون می‌آید. `void` یعنی خروجی نداری. فقط اثر، مثل چاپ، مانده است.

overloading یعنی چند متد با یک نام و پارامتر متفاوت. کامپایلر از روی تعداد و نوع آرگومان تصمیم می‌گیرد کدام بدن اجرا شود. نوع برگشت به‌تنهایی دو متد را از هم جدا نمی‌کند.

آرایهٔ `int[]` یک شیء است با طول ثابت. `length` تعداد خانه‌هاست، نه آخرین اندیس. اندیس از صفر شروع می‌شود. `int[] scores = {18, 17, 20};` هم طول را می‌سازد هم مقدار اولیه را می‌گذارد. خانهٔ نساختهٔ `int` صفر است.

`for` معمولی وقتی اندیس را لازم داری. `for (int n : scores)` هر عنصر را به نوبت در `n` می‌گذارد و اندیس نمی‌دهد. برای جمع و بیشینه همین کافی است.

جاوا پارامتر را با کپی مقدار می‌فرستد. برای `int`، عوض کردن پارامتر داخل متد، متغیر بیرون را عوض نمی‌کند. برای آرایه، آن مقدارِ کپی‌شده خودش یک ارجاع است. متد آرایهٔ تازه نمی‌بیند. همان خانه‌ها را می‌بیند. پس `items[0] = 1` آرایهٔ صدازننده را عوض می‌کند. `items = new int[3]` فقط متغیر محلی متد را عوض می‌کند و بیرون هیچ اثری ندارد.

اگر آرایه خالی است، `length` صفر است. میانگین را بر صفر تقسیم نکن. اول طول را ببین، یک جمله چاپ کن و برگرد.

## قاعده

هر محاسبه یک متد با ورودی و خروجی معلوم. اگر نتیجه را لازم داری، `void` ننویس. اگر آرایهٔ ورودی باید سالم بماند، خانهٔ جدید را در یک آرایهٔ تازه بنویس، نه در همان آرایه. نام یک متد را برای دو کار فقط وقتی تکرار کن که پارامترها فرق دارند.

## مثال

```java
static double average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}
```

تقسیم بر `3.0` حاصل را اعشاری می‌کند. تقسیم بر `3` آن را قطع می‌کند.

```java
static int max(int[] scores) {
    int best = scores[0];
    for (int n : scores) {
        if (n > best) {
            best = n;
        }
    }
    return best;
}
```

این شکل فرض می‌کند آرایه حداقل یک خانه دارد. خالی بودن را قبل از `scores[0]` جدا کن.

## اشتباه رایج

برگرداندن همان آرایهٔ ورودی بعد از عوض کردن خانه‌هایش، وقتی قرار بوده یک آرایهٔ تازهٔ برعکس بسازی. چاپِ قبل و بعد یکی می‌شود، چون هر دو نام به یک شیء اشاره می‌کنند.

## تمام است وقتی

یک محاسبه را از `main` بیرون بکشی، ورودی و خروجی متد را خودت انتخاب کنی، و روی یک آرایه میانگین و بیشینه را با متد خودت حساب کنی.
