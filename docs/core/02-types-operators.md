# فاز ۲ — نوع، متغیر و عملگر

این درسنامه برای Java 21 است. متغیر یک نام برای یک مقدار است، و نوع می‌گوید آن مقدار چه شکل محاسبه‌ای دارد. نوع غلط، نتیجه را بی‌صدا خراب می‌کند.

## چرا این‌طور کار می‌کند

`int` عدد صحیح است، معمولاً همان عددی که می‌شماری. `long` هم صحیح است، برای عدد بزرگ‌تر از محدودهٔ `int`. `double` بخش اعشاری دارد. `boolean` فقط `true` یا `false` است. `char` یک نویسه است و با نقل‌قول تکی نوشته می‌شود. `String` متن است و با نقل‌قول دوتایی. `String` و `System` در `java.lang` هستند و import نمی‌خواهند.

نام متغیر با حرف کوچک شروع می‌شود و مرز کلمه را با حرف بزرگ نشان می‌دهد: `birthYear`. نام، نوع را عوض نمی‌کند. نوع را خودت موقع اعلام انتخاب می‌کنی.

`+ - * / %` همان چهار عمل و باقی‌مانده‌اند. اگر هر دو طرف `/` از نوع `int` باشند، جاوا حاصل را به سمت صفر قطع می‌کند: `1 / 2` می‌شود `0`، نه `0.5`. برای تقسیم اعشاری حداقل یک طرف باید `double` باشد. تبدیل صریح `(double) a / b` اول `a` را اعشاری می‌کند و بعد تقسیم می‌کند. اگر پرانتز را دور کل تقسیم بگذاری، اول قطع می‌شود و بعد تبدیل، فایده ندارد.

`+` بین دو `String` متن را به هم می‌چسباند. `==` برای `String` مقایسهٔ هویت شیء است، نه مقایسهٔ حرف‌ها. دو متن با حرف‌های یکسان ممکن است دو شیء باشند. مقایسهٔ متن با `equals` است.

ورودی را با `Scanner` می‌گیری و فقط این را import می‌کنی: `import java.util.Scanner;`. `nextInt` یک `int` می‌خواند. `next` یک کلمه. text block با `"""` چند خط را یک `String` می‌کند. خط اول محتوا از خط بعد از `"""` شروع می‌شود، و تورفتگی مشترک خط‌ها از خود متن حذف می‌شود.

## قاعده

برای میانگین و برای تقسیمی که جزء اعشاری می‌خواهی، `double` را وارد محاسبه کن، نه بعد از قطع شدن. متن را با `equals` بسنج. اگر ورودی عدد نیست، نوع متغیر را به امید شانس عوض نکن. اول بگو آن مقدار صحیح است یا اعشاری یا متن.

## مثال

```java
int passed = 1;
int total = 2;
double ratio = (double) passed / total;
```

این `ratio` برابر `0.5` است. بدون تبدیل، `passed / total` همان `0` است.

```java
String choice = scanner.next();
if (choice.equals("خروج")) {
    System.out.println("خداحافظ");
}
```

منوی چندخطی را با text block بنویس. تصمیم منو مال فاز ۳ است. اینجا فقط ساختن متن و مقایسهٔ آن است.

## اشتباه رایج

`1 / 2` را مساوی نصف گرفتن. هر دو عملوند `int` هستند، پس حاصل `int` است و به سمت صفر قطع می‌شود. برای نمره و دما این باگ بی‌صدا است: برنامه خطا نمی‌دهد و عدد غلط چاپ می‌کند.

## تمام است وقتی

برای یک محاسبهٔ کوچک نوع مناسب را انتخاب کنی، ورودی عددی بگیری، و دو رشته را با `equals` مقایسه کنی نه با `==`.
