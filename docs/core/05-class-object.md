# فاز ۵ — کلاس و شیء

این درسنامه برای Java 21 است. class نقشه است. شیء یک نمونهٔ ساخته‌شده از آن نقشه است، با وضعیت خودش. دو نام که به یک شیء اشاره کنند، دو وضعیت نیستند.

## چرا این‌طور کار می‌کند

`new` شیء را می‌سازد و یک سازنده را صدا می‌زند. سازنده هم‌نام class است و نوع برگشت ندارد. کارش این است که فیلدها را از همان اول مقدار درست بدهد. `this` یعنی همین شیء. وقتی نام پارامتر با نام فیلد یکی است، `this.balance = balance` فیلد را از پارامتر جدا می‌کند.

فیلد `private` را از بیرون class نمی‌شود مستقیم خواند یا نوشت. تغییر فقط از متد خود class می‌گذرد. این encapsulation است: قانون موجودی داخل `withdraw` می‌ماند، نه در هر `main` که دلش خواست `balance` را کم کند.

متد instance به یک شیء تعلق دارد و فیلدهای همان شیء را می‌بیند. متد `static` شیء نمی‌خواهد و `this` ندارد. فیلد `static` یکی است برای همهٔ شیءهای آن class. تعداد حساب‌های ساخته‌شده فیلد `static` است. موجودی هر حساب فیلد instance است. اگر موجودی را `static` کنی، واریز به یک حساب موجودی همه را عوض می‌کند.

`toString` متنی است که موقع چاپ شیء نشان داده می‌شود. `println` خودش آن را صدا می‌زند. اگر ننویسی، متن پیش‌فرض نام class و یک عدد است، نه عنوان کتاب.

`package` پوشهٔ منطقی class است. خط اول فایل `package bank;` یعنی فایل باید در پوشهٔ `bank` باشد. اجرا را از پوشهٔ بالاتر می‌زنی، چون نام کامل class از ریشهٔ classpath است: `bank.BankAccount`. `javac -d .` همان درخت بسته را در خروجی می‌سازد.

`public` را بیرون بسته هم می‌شود دید. `private` فقط خود class. `protected` را فاز ۶، کنار وراثت، می‌بینیم.

## قاعده

وضعیت را `private` نگه دار و فقط با متد عوض کن. چیزی که مال هر شیء است فیلد معمولی است. چیزی که مال خود class است `static` است. دو شیء یعنی دو بار `new`. اگر یکی را عوض کردی و دیگری هم عوض شد، یا هر دو نام یک شیءاند، یا فیلد را اشتباهاً `static` کرده‌ای.

## مثال

```java
package bank;

public class BankAccount {
    private int balance;

    public BankAccount(int balance) {
        this.balance = balance;
    }

    public int getBalance() {
        return balance;
    }
}
```

```bash
javac -d . bank/BankAccount.java
java bank.BankAccount
```

فرمان دوم فقط وقتی `main` داشته باشد چیزی چاپ می‌کند. مسیر مهم است: از داخل پوشهٔ `bank` دستور `java BankAccount` نام بسته را گم می‌کند.

## اشتباه رایج

یک شیء ساختن و دو متغیر را به آن نسبت دادن، بعد تعجب کردن که افزایش یکی، دیگری را هم زیاد کرده. `Counter b = a` شیء دوم نمی‌سازد. `new` دوم می‌سازد.

## تمام است وقتی

یک class با فیلد `private`، سازنده و متد بنویسی، دو شیء جدا بسازی، و بتوانی توضیح بدهی کدام داده مال شیء است و کدام `static` است.
