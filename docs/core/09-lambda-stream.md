# فاز ۹ — Lambda و Stream

این درسنامه برای Java 21 است. lambda یک تابع کوتاه بی‌نام است. Stream زنجیره‌ای از فیلتر و تبدیل روی یک مجموعه است. جای هر حلقهٔ ساده را نمی‌گیرد.

## چرا این‌طور کار می‌کند

`n -> n >= 10` یعنی «این مقدار را بگیر و بگو آیا از ۱۰ کمتر نیست». اگر پارامتر یکی باشد پرانتز لازم نیست. اگر بدنه یک جمله نباشد، آکولاد و `return` می‌خواهد. method reference وقتی است که lambda فقط یک متد موجود را صدا می‌زند: `System.out::println` همان کاری را می‌کند که `n -> System.out.println(n)`.

`Stream` را از روی `List` با `.stream()` می‌گیری. تا یک عمل پایانی نرسیده، کاری انجام نمی‌شود. `filter` بعضی عنصرها را نگه می‌دارد. `map` هر عنصر را به یک عنصر تازه بدل می‌کند. `sorted` مرتب می‌کند. `toList` نتیجه را در یک `List` تازه می‌گذارد. این زنجیره لیست منبع را عوض نمی‌کند، به شرطی که خودت داخل lambda به آن لیست دست نزنی.

برای عدد، `mapToInt` از جعبهٔ `Integer` درمی‌آید و `IntStream` می‌سازد. `average` میانگین را در `OptionalDouble` می‌گذارد، چون لیست ممکن است خالی باشد. `count` تعداد است. روی لیست خالی `getAsDouble` نزن. خالی بودن را ببین و جملهٔ خودت را چاپ کن، مثلاً «نمره‌ای نیست».

`Optional` یعنی شاید مقدار نباشد. `isPresent` می‌پرسد هست یا نه. `orElse` اگر نباشد یک مقدار جایگزین می‌دهد. این جایگزینِ `null` است که همان لحظهٔ استفاده `NullPointerException` بسازد. اگر جست‌وجو کسی را پیدا نکرد، `Optional` خالی برگردان و در چاپ بگو «پیدا نشد»، نه اینکه روی `null` متد صدا بزنی.

برای یک پیمایش که فقط چاپ یا یک جمع ساده است، `for` واضح‌تر است. Stream را وقتی بیاور که زنجیرهٔ فیلتر و تبدیل داری و خواندن آن زنجیره از حلقهٔ تو در تو راحت‌تر است. همان تبدیل را یک بار با `for` هم بنویس تا این فرق را خودت ببینی، نه به‌عنوان قاعدهٔ حفظی.

## قاعده

منبع را وسط Stream عوض نکن. نتیجه را با `toList` بگیر، نه با لیستی که از بیرون در lambda پرش می‌کنی. برای میانگین، خالی بودن `OptionalDouble` را جدا کن. نبودن یک عنصر را `Optional` خالی کن، نه `null`.

## مثال

```java
List<String> names = List.of("علی", "سارا", "امیررضا");
names.stream()
    .filter(name -> name.length() > 3)
    .sorted()
    .forEach(System.out::println);
```

```java
OptionalDouble average = scores.stream().mapToInt(n -> n).average();
if (average.isPresent()) {
    System.out.println(average.getAsDouble());
} else {
    System.out.println("نمره‌ای نیست");
}
```

`scores` اینجا `List<Integer>` است. اگر خالی باشد شاخهٔ دوم اجرا می‌شود و برنامه نمی‌ترکد.

## اشتباه رایج

صدا زدن `average.getAsDouble()` بدون پرسیدن `isPresent`. لیست خالی مقدار ندارد، و این فراخوانی همان استثنای عجیبی است که نباید به کاربر نشان بدهی.

## تمام است وقتی

یک لیست را با lambda فیلتر و map کنی، نتیجه را با `toList` بگیری، و نبودن یک مقدار را با `Optional` به `NullPointerException` تبدیل نکنی.
