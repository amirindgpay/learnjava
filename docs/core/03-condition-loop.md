# فاز ۳ — شرط و حلقه

این درسنامه برای Java 21 است. شرط یک بار راه را عوض می‌کند. حلقه همان کار را تا وقتی یک جملهٔ پایان برقرار است تکرار می‌کند. اگر آن جمله را ننویسی، حلقه یا هیچ‌وقت تمام نمی‌شود یا یک بار کم و زیاد می‌رود.

## چرا این‌طور کار می‌کند

`if` بدنه را فقط وقتی شرط `true` است اجرا می‌کند. `else if` شرط بعدی است، به شرطی که قبلی‌ها غلط بوده باشند. `else` یعنی هیچ‌کدام. شرط‌ها از بالا به پایین امتحان می‌شوند. اگر دو شرط می‌توانند هم‌زمان راست باشند، ترتیبی که نوشته‌ای تصمیم می‌گیرد، نه «منطق طبیعی» داخل سرت.

`switch` یک مقدار را به چند شاخه می‌فرستد. شکل کلاسیک با `:` به شاخهٔ بعدی نشت می‌کند مگر `break` بگذاری. شکل فلش (`->`) از Java 14 استاندارد است و نشت نمی‌کند. `switch` expression مقدار برمی‌گرداند. روی `int` باید `default` داشته باشد، چون جاوا همهٔ عددها را از روی چند `case` حدس نمی‌زند.

`while` اول شرط را می‌بیند. اگر از همان اول غلط باشد، بدنه صفر بار اجرا می‌شود. `do-while` بدنه را یک بار اجرا می‌کند و بعد شرط را می‌بیند. `for` وقتی است که شمارهٔ تکرار را خودت می‌دانی: مقدار شروع، شرط ادامه، و قدم بعد از هر دور. هر سه شکل یک کار را می‌کنند. فرقی که برای تو مهم است این است که شرط کی سنجیده می‌شود.

`break` از نزدیک‌ترین حلقه بیرون می‌پرد. `continue` بقیهٔ همین دور را رد می‌کند و به شرط دور بعد می‌رود. هیچ‌کدام جای شرط پایان نیستند. شرط پایان را قبل از نوشتن حلقه، یک جملهٔ فارسی بنویس: «تمام می‌شود وقتی …». اگر آن جمله را نداری، حلقه را شروع نکن.

## قاعده

یک تصمیمِ یک‌باره `if` است. کار تکراری حلقه است، و قبل از کد بگو دور آخر کدام است. برای چند حالت روی یک مقدار، `switch` فلش‌دار بنویس تا فراموش کردن `break` نتیجه را عوض نکند.

## مثال

```java
String label = switch (choice) {
    case 1 -> "جمع";
    case 2 -> "تفریق";
    default -> "نامشخص";
};
```

```java
int n = 1;
while (n <= 10) {
    System.out.println(n);
    n = n + 1;
}
```

جملهٔ پایان این حلقه: تمام می‌شود وقتی `n` از ۱۰ بزرگ‌تر شود. اگر خط `n = n + 1` را برنداری، شرط همیشه راست می‌ماند.

## اشتباه رایج

`switch` کلاسیک بدون `break`. اجرا وارد `case` درست می‌شود و از آنجا تا آخر، `case`های بعدی را هم انجام می‌دهد. شکل فلش این نشت را ندارد. اگر شکل کلاسیک می‌نویسی، هر شاخه را خودت ببند.

## تمام است وقتی

برای یک کار، خودت تصمیم بگیری `if` کافی است یا حلقه لازم است، و بتوانی بگویی حلقه کی تمام می‌شود.
